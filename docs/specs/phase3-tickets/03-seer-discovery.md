# 03: รายชื่อหมอดูจากฐานข้อมูลจริง

**What to build:** ผู้ใช้ที่ login แล้วเห็นรายชื่อหมอดูที่เปิดรับงานจริงจากฐานข้อมูล พร้อมราคาเป็นจำนวนเหรียญ
ที่ server กำหนด ค้นหาด้วยชื่อหรือความถนัดได้ กดเข้าไปดูรายละเอียดหมอดูและบริการก่อนตัดสินใจได้
ถ้าไม่มีหมอดูต้องเห็นหน้าจอที่บอกสถานะชัดเจน ไม่ใช่หน้าว่าง

ใช้หน้าจอเดิมที่มีอยู่ ต่อสายใหม่เข้าไป ไม่ปรับดีไซน์

**Blocked by:** 01 (Fixture), 02 (Login + wallet)

**Status:** ready-for-agent

- [ ] รายชื่อมาจากตารางจริงผ่าน RLS ไม่มีข้อมูล hardcode เหลือในเส้นทางนี้
- [ ] ราคาที่แสดงคือ `price_coin` จาก `seer_service` ตรง ๆ — แอปไม่คำนวณหรือจัดรูปแบบราคาเอง
- [ ] หมอดูที่ปิดรับงาน / retire แล้ว ไม่โผล่ในรายการ
- [ ] ค้นหาด้วยชื่อและความถนัดได้
- [ ] มี empty state และ error state ที่แยกออกจากกันได้ด้วยตา
- [ ] integration test: fixture สร้างหมอดู 1 คน → รายการต้องเห็น 1 คน; ปิด `accepts_question` → ต้องหายไป
