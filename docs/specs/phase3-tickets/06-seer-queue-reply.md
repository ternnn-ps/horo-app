# 06: ฝั่งหมอดู — คิวงาน + ตอบคำถาม

**What to build:** login ด้วยบัญชีหมอดู เห็นคิวคำถามที่เข้ามาและยังไม่ได้ตอบ กดเข้าไปตอบได้
พอตอบข้อความแรก question เลื่อนสถานะเป็น `active` เอง (trigger ทำให้อยู่แล้ว หมอดูไม่ต้องกดอะไรเพิ่ม)
· คำถามใหม่เข้าคิวเองโดยไม่ต้องรีเฟรช · ไม่มีงานค้างต้องเห็นหน้าจอที่บอกชัดเจน

ใช้หน้าจอฝั่ง seer เดิมที่มีอยู่ ต่อสายใหม่เข้าไป

**Blocked by:** 05 (Chat + Realtime)

**Status:** ready-for-agent

- [ ] คิวแสดงเฉพาะคำถามของหมอดูคนนั้นจริง (RLS พิสูจน์ด้วยบัญชีที่สอง)
- [ ] หมอดูตอบข้อความแรก → สถานะเปลี่ยนเป็น `active` โดยแอปไม่ได้สั่งเปลี่ยนเอง
- [ ] คำถามใหม่เข้ามาระหว่างเปิดหน้าคิวอยู่ → โผล่เองผ่าน Realtime
- [ ] มี empty state ของ "ไม่มีงานค้าง"
- [ ] integration test: user ซื้อคำถาม → seer เห็นในคิว → seer ตอบ → status = `active` และเหรียญยัง reserved อยู่ (ยังไม่ถึงมือใคร)
