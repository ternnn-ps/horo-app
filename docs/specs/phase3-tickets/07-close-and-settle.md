# 07: ปิดงาน — เงินออกจาก escrow เข้ากระเป๋าหมอดู

**What to build:** หมอดูตอบครบแล้วกดขอปิดงาน → ผู้ใช้เห็นคำขอและกดยืนยันหรือปฏิเสธได้ →
เมื่อยืนยัน เหรียญที่กันไว้ออกจาก escrow เข้าเป็นยอดค้างจ่ายของหมอดูจริง และทั้งสองฝั่งเห็นตัวเลขขยับ
· ผู้ใช้ยกเลิกคำถามที่หมอดูยังไม่ตอบได้ และได้เหรียญคืนเต็มจำนวน

**นี่คือก้อนที่ทำให้ money loop ครบวงเป็นครั้งแรกจาก client จริง**

**Blocked by:** 06 (Seer queue + reply)

**Status:** ready-for-agent

- [ ] หมอดูขอปิด → ผู้ใช้เห็นคำขอ (ผ่าน Realtime หรือตอนเปิดห้อง) และเลือกได้สองทาง
- [ ] ยืนยันปิด → `reserved_coin` ของผู้ใช้ลดเป็น 0 สำหรับงานนั้น, `payable_coin` ของหมอดูเพิ่มตามส่วนแบ่ง, ledger สมดุล
- [ ] ปฏิเสธการปิด → กลับไปคุยต่อได้ เหรียญยังกันไว้เหมือนเดิม
- [ ] ยกเลิกคำถามก่อนหมอดูตอบ → คืนเหรียญเต็มจำนวน สถานะเป็น `cancelled_refunded`
- [ ] หน้าจอฝั่งหมอดูเห็นยอดค้างจ่ายของตัวเองเพิ่มขึ้นจริง
- [ ] integration test เดินครบลูป: ซื้อ → ตอบ → ขอปิด → ยืนยัน → ตรวจยอดทั้งสองกระเป๋า + ตรวจ ledger สมดุล
- [ ] integration test: ผู้ใช้เรียก RPC ที่เป็นของ service_role → ถูกปฏิเสธ
