# 02: หมอดูผูกบัญชีธนาคาร แล้วแอดมินตรวจ

**What to build:** หมอดูกรอกธนาคาร เลขบัญชี และชื่อบัญชีในแอป · บันทึกแล้วหน้าจอโชว์แค่
4 ตัวท้ายกับสถานะการตรวจ · แอดมินเทียบชื่อบัญชีกับเอกสาร KYC ที่หมอดูยื่นไว้ตอนสมัคร
แล้วกดผ่านหรือปฏิเสธพร้อมเหตุผล · หมอดูเห็นผลและแก้แล้วยื่นใหม่ได้

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] บันทึกบัญชีแล้วแอปแสดงเฉพาะ 4 ตัวท้าย ไม่มีเส้นทางไหนที่ client อ่านเลขบัญชีเต็มได้
- [ ] เลขบัญชีเต็มอ่านได้เฉพาะฝั่งเซิร์ฟเวอร์ และทุกครั้งที่อ่านมีบันทึกไว้ใน audit
- [ ] หมอดูมีบัญชีรับเงินที่ใช้งานอยู่ได้ทีละหนึ่ง
- [ ] แก้บัญชีแล้วสถานะกลับไปเป็น "รอตรวจ" เอง — ไม่ใช่ยังผ่านอยู่ด้วยข้อมูลใหม่ที่ยังไม่มีใครดู
- [ ] แอดมินปฏิเสธพร้อมเหตุผล แล้วหมอดูเห็นเหตุผลนั้น
- [ ] หมอดูคนอื่นอ่านบัญชีของเราไม่เห็น
- [ ] ผู้ใช้ทั่วไปเรียกคำสั่งฝั่งแอดมินไม่ได้
- [ ] ทุกการเปลี่ยนสถานะทำผ่านคำสั่งที่มี audit ไม่ใช่การแก้แถวตรง ๆ
