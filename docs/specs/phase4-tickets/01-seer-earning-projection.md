# 01: หมอดูเห็นรายการรายได้ของตัวเอง

**What to build:** หมอดูเปิดแอปแล้วเห็นว่ารายได้แต่ละก้อนมาจากงานไหน ลูกค้าจ่ายมาเท่าไหร่
หักส่วนแบ่งแพลตฟอร์มแล้วเหลือเท่าไหร่ และเกิดขึ้นเมื่อไหร่ — ตรวจได้ว่าแพลตฟอร์มคิดถูก

ก้อนนี้เป็นฐานของทั้งเฟส เพราะ **ระยะรอก่อนถอนได้คิดจากวันที่ของรายได้แต่ละก้อน**
ถ้าไม่มี projection นี้ก็ไม่มีทางรู้ว่าเหรียญก้อนไหนสุกแล้ว · ตอนนี้ตอนปิดงานระบบโพสต์ ledger
อย่างเดียว ไม่ได้บันทึกว่ารายได้ก้อนนั้นมาจากงานอะไร (คอมเมนต์ใน migration เขียนไว้เองว่ายกไปทีหลัง)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] ปิดงานหนึ่งครั้ง → เกิดรายการรายได้หนึ่งรายการ ในทรานแซกชันเดียวกับ ledger ไม่ใช่คนละจังหวะ
- [ ] รายการเก็บอัตราส่วนแบ่ง ณ ตอนนั้นไว้ด้วย — เปลี่ยนอัตราทีหลังแล้วรายการเก่าต้องไม่เปลี่ยนตาม
- [ ] งานเดียวสร้างรายได้ได้ครั้งเดียว ต่อให้ยิง settle ซ้ำ
- [ ] รายได้ที่ปิดงานไปแล้วก่อนมี ticket นี้ ถูกเติมย้อนหลังจาก ledger จนยอดรวมตรงกับ `payable_coin` ปัจจุบัน
- [ ] แต่ละรายการโยงกลับไปหาหลักฐานทางบัญชีใน ledger ได้
- [ ] หมอดูอ่านของตัวเองได้ อ่านของคนอื่นไม่ได้ (พิสูจน์ด้วยบัญชีที่สอง)
- [ ] หมอดูเขียนทับรายการเองไม่ได้
- [ ] แอปแสดงรายการรายได้ให้หมอดูเห็นจริงบนหน้าจอ ไม่ใช่แค่มีข้อมูลในฐาน
