# 04: ปิดวงจร — อนุมัติ ปฏิเสธ ยกเลิก และโอนจริง

**What to build:** แอดมินเห็นคิวคำขอถอนเรียงตามเวลา กดอนุมัติหรือปฏิเสธพร้อมเหตุผล
โอนเงินผ่านแอปธนาคารจริงแล้วกลับมาบันทึกเลขอ้างอิงว่าโอนแล้ว · หมอดูเห็นสถานะทุกขั้น
เห็นเลขอ้างอิงหลังโอนสำเร็จ และยกเลิกเองได้ตราบใดที่ยังไม่โอน · เหรียญกลับมาครบทุกกรณีที่ไม่ได้เงิน

**Blocked by:** 03 (ขอถอน)

**Status:** ready-for-agent

- [ ] แอดมินอนุมัติ → หมอดูเห็นสถานะเปลี่ยน
- [ ] แอดมินปฏิเสธพร้อมเหตุผล → เหรียญกลับเข้ายอดค้างจ่ายครบ และหมอดูเห็นเหตุผล
- [ ] หมอดูยกเลิกเองได้ก่อนโอน → เหรียญกลับมาครบ
- [ ] ยกเลิก/ปฏิเสธหลังโอนแล้ว → ทำไม่ได้
- [ ] การคืนเหรียญทำด้วยรายการกลับรายการ **ไม่ใช่การแก้รายการเดิม** และกลับซ้ำสองครั้งไม่ได้
- [ ] กดว่าโอนแล้วต้องกรอกเลขอ้างอิง จะปล่อยว่างไม่ได้
- [ ] หมอดูเห็นประวัติการถอนย้อนหลังทั้งหมดพร้อมสถานะและเลขอ้างอิง
- [ ] หมอดูคนอื่นอ่านคำขอของเราไม่เห็น
- [ ] ผู้ใช้ทั่วไปเรียกคำสั่งแอดมินไม่ได้
- [ ] แอดมินหาคำขอที่ค้างเกินกำหนดเจอ
- [ ] ledger สมดุลหลังเดินครบทุกเส้นทาง (อนุมัติ→โอน / ปฏิเสธ / ยกเลิก)
