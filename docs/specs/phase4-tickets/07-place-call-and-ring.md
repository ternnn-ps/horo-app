# 07: กดโทร เหรียญถูกกัน แล้วหมอดูมีสายเรียกเข้า

**What to build:** ผู้ใช้เลือกแพ็กแล้วกดโทร เหรียญถูกกันไว้ทันทีและเห็นชัดว่ากันไปเท่าไหร่
· ฝั่งหมอดูมีสายเรียกเข้าพร้อมเสียงในแอป เห็นชื่อผู้โทรและแพ็กที่เลือก กดรับหรือปฏิเสธได้
· ผู้ใช้ยกเลิกระหว่างรอได้ · ไม่มีคนรับภายในเวลาที่กำหนดแล้วสายหมดอายุเอง
· **ทุกทางที่ไม่ได้คุยกัน เหรียญต้องกลับมาครบ**

ก้อนนี้ยังไม่มีเสียงสนทนาจริง (อยู่ ticket 08) — ที่พิสูจน์คือเงินกับสถานะเดินถูก

**Blocked by:** 05 (แพ็ก), 06 (สถานะออนไลน์)

**Status:** ready-for-agent

- [ ] กดโทร → เหรียญย้ายจากยอดใช้ได้ไปเป็นยอดที่ถูกกัน ผลรวมไม่เปลี่ยน
- [ ] เหรียญไม่พอ → รู้ก่อนกดโทร และถ้าหลุดไปถึงเซิร์ฟเวอร์ต้องถูกปฏิเสธโดย**ไม่มีสายเกิดขึ้น**
- [ ] มีสายค้างอยู่แล้วโทรอีก → ถูกปฏิเสธ
- [ ] หมอดูที่กำลังคุยอยู่ ไม่มีสายใหม่เข้าไปพร้อมกัน
- [ ] หมอดูได้รับสายเรียกเข้าเองโดยไม่ต้องรีเฟรช และ**เปิดหน้าคิวก็ต้องเห็นสายที่ค้างอยู่** ไม่พึ่งการแจ้งเตือนอย่างเดียว
- [ ] หมอดูปฏิเสธ → เหรียญคืนครบ
- [ ] ผู้ใช้ยกเลิกก่อนมีคนรับ → เหรียญคืนครบ
- [ ] ไม่มีใครรับจนหมดเวลา → สายหมดอายุเองและเหรียญคืนครบ แม้ไม่มีใครเปิดแอปอยู่
- [ ] ราคาที่กันไว้ snapshot จากแพ็ก ณ ตอนโทร — หมอดูขึ้นราคาระหว่างนั้นไม่กระทบสายที่จองแล้ว
- [ ] คนนอกอ่านสายของคนอื่นไม่เห็น
- [ ] ledger สมดุลทุกเส้นทาง
