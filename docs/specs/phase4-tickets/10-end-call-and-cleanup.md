# 10: วางสาย เห็นสรุป และไม่มีเหรียญค้างในระบบ

**What to build:** ฝ่ายไหนก็วางสายได้ · จบแล้วผู้ใช้เห็นสรุปว่าคุยไปกี่นาที จ่ายไปกี่เหรียญ
รวมต่อเวลาแล้ว · หมอดูเห็นยอดค้างจ่ายเพิ่มขึ้นจริง · ทั้งสองฝั่งเห็นสายนั้นในประวัติ
· และ **ไม่มีสายไหนค้างจนเหรียญติดอยู่ใน escrow ตลอดไป** ต่อให้แอปดับกลางคัน

**Blocked by:** 09 (ต่อเวลา)

**Status:** ready-for-agent

- [ ] ผู้ใช้วางสายได้ และหมอดูก็วางสายได้
- [ ] สรุปหลังจบสายตรงกับที่หักไปจริง รวมต่อเวลาทุกครั้ง
- [ ] หมอดูเห็นยอดค้างจ่ายเพิ่มขึ้นบนหน้าจอ ไม่ใช่แค่ในฐาน
- [ ] ทั้งสองฝั่งเห็นสายในประวัติพร้อมเวลาและยอด
- [ ] สายที่ค้างสถานะกำลังคุยผิดปกติ ถูกปิดและตัดจบเงินได้เอง
- [ ] แอปดับกลางสาย → เปิดใหม่แล้วสถานะยังถูกต้อง อ่านจากฐานไม่ใช่จากหน่วยความจำในเครื่อง
- [ ] ไม่มีเหรียญค้างอยู่ในสถานะถูกกันโดยไม่มีสายที่ยังมีชีวิตอยู่
- [ ] เดินครบลูปแล้ว ledger สมดุลทุกธุรกรรม
