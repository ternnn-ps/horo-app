# 05: หมอดูตั้งแพ็กเวลาและราคาสำหรับสายโทร

**What to build:** หมอดูตั้งได้ว่ารับสายกี่แพ็ก แต่ละแพ็กกี่นาทีกี่เหรียญ (เช่น 15 นาที 150 เหรียญ,
30 นาที 280 เหรียญ) และตั้งแพ็กต่อเวลาแยกได้ · ผู้ใช้เปิดโปรไฟล์หมอดูแล้วเห็นแพ็กทั้งหมด
· หน้ารายชื่อแสดงราคาเป็น **เหรียญ/นาที** ที่คำนวณจากแพ็กสั้นสุด เพื่อให้เทียบข้ามหมอดูได้

**Blocked by:** None (can start immediately) — แต่ตามที่ตกลงกันไว้ ทำหลัง payout เสร็จ

**Status:** ready-for-agent

- [ ] หมอดูตั้งได้หลายแพ็กต่อหนึ่งบริการ — ของเดิมรองรับราคาเดียวต่อบริการเท่านั้น
- [ ] แพ็กแยกชนิดได้ว่าเป็นแพ็กเริ่มสาย หรือแพ็กต่อเวลา
- [ ] ราคาที่หมอดูตั้งถูกตรวจกับช่วงที่ระบบอนุญาต ตั้งเกินหรือติดลบไม่ได้
- [ ] ผู้ใช้เห็นแพ็กของหมอดูจากฐานข้อมูลจริง ไม่มีค่า hardcode ในเส้นทางนี้
- [ ] ราคาต่อนาทีที่แสดงคำนวณจากแพ็กจริง แอปไม่ตั้งราคาเอง
- [ ] หมอดูแก้ราคาแพ็กได้ และแก้ของคนอื่นไม่ได้
- [ ] แพ็กที่ปิดใช้งานไม่โผล่ให้ผู้ใช้เห็น
