# 08: ออกสิทธิ์เข้าห้องสนทนาให้เฉพาะคู่สนทนาจริง

**What to build:** ฝั่งเซิร์ฟเวอร์ออก "บัตรผ่าน" เข้าห้องสนทนาของสายหนึ่ง ๆ ให้เฉพาะผู้โทรกับหมอดู
ที่เป็นคู่สนทนาของสายนั้นจริง และเฉพาะตอนที่สายยังไม่จบ · คนอื่นขอไม่ได้ สายที่จบแล้วขอไม่ได้

แยกออกมาจากก้อน "ได้ยินเสียง" เพราะนี่คือ**ด่านสิทธิ์** ซึ่งพลาดแล้วแปลว่าคนนอกแอบฟัง
คนอื่นดูดวงได้ · ทดสอบได้ครบโดยยังไม่ต้องแตะแอปเลย

**Blocked by:** 07 (จองสาย + เรียกเข้า)

**Status:** ready-for-agent

- [ ] ผู้โทรของสายนั้นขอบัตรผ่านได้
- [ ] หมอดูของสายนั้นขอบัตรผ่านได้
- [ ] คนที่ไม่ใช่คู่สนทนาขอ → ถูกปฏิเสธ (พิสูจน์ด้วยบัญชีที่สาม)
- [ ] สายที่จบ/ถูกยกเลิก/หมดอายุแล้ว → ขอไม่ได้
- [ ] ยังไม่ได้เข้าสู่ระบบ → ขอไม่ได้
- [ ] บัตรผ่านมีวันหมดอายุ ไม่ใช่ใช้ได้ตลอดไป
- [ ] ตัวบัตรผ่านไม่ถูกเก็บลงฐานข้อมูล เก็บแค่ว่าออกให้ใครเมื่อไหร่เพื่อตรวจย้อนหลัง
- [ ] client อ่านตารางห้องสนทนาตรง ๆ ไม่ได้
