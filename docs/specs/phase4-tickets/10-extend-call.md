# 10: ต่อเวลาระหว่างคุยโดยไม่ต้องวางสาย

**What to build:** ใกล้หมดเวลาระบบเตือนทั้งสองฝั่ง · ผู้ใช้กดต่อเวลาเป็นก้อนตามแพ็กที่หมอดูตั้งไว้
เหรียญถูกหักทันทีและเวลาเพิ่มขึ้นโดยบทสนทนาไม่ขาดตอน · หมอดูรู้ทันทีว่าต่อเวลาสำเร็จ
· เหรียญไม่พอต้องรู้ทันทีและ**ต้องไม่เกิดการต่อเวลาครึ่ง ๆ กลาง ๆ**

**Blocked by:** 09 (คุยได้จริง)

**Status:** ready-for-agent

- [ ] ต่อเวลาสำเร็จ → หักจากยอดใช้ได้ตรง ๆ ไม่ผ่านการกันเหรียญ และเวลาที่เหลือเพิ่มขึ้นทั้งสองฝั่ง
- [ ] เหรียญไม่พอ → ถูกปฏิเสธ **ไม่มีรายการต่อเวลาเกิดขึ้น** และเหรียญไม่ขยับ
- [ ] ยิงคำสั่งต่อเวลาซ้ำด้วยลำดับเดิม → ไม่เกิดรายการซ้ำและไม่หักเงินรอบสอง
- [ ] ต่อเวลาได้หลายครั้งในสายเดียว และแต่ละครั้งบันทึกราคา ณ ตอนนั้น
- [ ] ต่อเวลาสายที่จบไปแล้ว → ทำไม่ได้
- [ ] คนที่ไม่ใช่ผู้โทรสั่งต่อเวลาไม่ได้
- [ ] ทั้งสองฝั่งถูกเตือนก่อนหมดเวลา
- [ ] ledger สมดุล
