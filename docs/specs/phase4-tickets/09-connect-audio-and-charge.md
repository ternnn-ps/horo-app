# 09: ได้ยินเสียงกันจริง และเงินออกจาก escrow

**What to build:** หมอดูกดรับแล้วทั้งสองฝั่งเข้าห้องสนทนาและ**ได้ยินเสียงกันจริง**
· เมื่อสายเริ่มจริง เหรียญที่กันไว้ถูกจ่ายออก — เข้ายอดค้างจ่ายของหมอดูตามส่วนแบ่ง
ที่เหลือเป็นรายได้แพลตฟอร์ม · ทั้งสองฝั่งเห็นเวลาที่เหลือระหว่างคุย
· ถ้าต่อห้องไม่สำเร็จภายในเวลาผ่อนผัน ต้องคืนเหรียญ ไม่ใช่คิดเงินฟรี

**Blocked by:** 08 (สิทธิ์เข้าห้อง), 01 (รายการรายได้ — การจบสายต้องเขียน projection เดียวกับการจบคำถาม)

**Status:** ready-for-agent

- [ ] สองเครื่องเข้าห้องเดียวกันแล้วได้ยินเสียงกันจริง (ทดสอบด้วยมือสองเครื่อง)
- [ ] เริ่มคุย → เหรียญออกจากยอดที่ถูกกัน เข้ายอดค้างจ่ายหมอดูตามส่วนแบ่ง ส่วนที่เหลือเป็นรายได้แพลตฟอร์ม
- [ ] เกิดรายการรายได้ให้หมอดูหนึ่งรายการ (เชื่อมกับ ticket 01 → ถอนออกได้จริงตามระยะรอ)
- [ ] ยิงคำสั่งเริ่มสายซ้ำ → ไม่จ่ายเงินรอบสอง
- [ ] ต่อห้องไม่สำเร็จในเวลาผ่อนผัน → เหรียญคืนครบ
- [ ] ทั้งสองฝั่งเห็นเวลาที่เหลือตรงกัน
- [ ] ledger สมดุล
