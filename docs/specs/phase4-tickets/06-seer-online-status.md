# 06: รู้ว่าหมอดูคนไหนรับสายได้ตอนนี้

**What to build:** หมอดูเปิดสวิตช์ "พร้อมรับสาย" ในแอป · ผู้ใช้เห็นสถานะออนไลน์บนรายชื่อ
และกรองเฉพาะคนที่ออนไลน์อยู่ตอนนี้ได้ · **หมอดูที่ปิดแอปไปต้องหลุดออนไลน์เอง** ไม่ใช่ค้างสถานะไว้
แล้วผู้ใช้โทรไปไม่มีคนรับ · หมอดูที่ออฟไลน์แสดงทางเลือกส่งคำถามแบบข้อความแทน

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] หมอดูเปิด/ปิดสวิตช์แล้วผู้ใช้เห็นการเปลี่ยนแปลง
- [ ] ปิดแอปทิ้งไว้ → สถานะกลายเป็นออฟไลน์เองภายในเวลาที่กำหนด โดยไม่ต้องมีใครกดอะไร
- [ ] กรอง "ออนไลน์ตอนนี้" ได้จากฝั่งเซิร์ฟเวอร์ ไม่ใช่ดึงมาทั้งหมดแล้วกรองในแอป
- [ ] หมอดูออฟไลน์ → ปุ่มโทรหายไป และเห็นทางเลือกส่งคำถามข้อความแทน
- [ ] หมอดูแก้สถานะของคนอื่นไม่ได้
- [ ] สถานะที่ผู้ใช้เห็นตรงกับความจริงว่าหมอดูเปิดแอปอยู่จริง ไม่ใช่แค่ค่าที่ค้างในฐาน
