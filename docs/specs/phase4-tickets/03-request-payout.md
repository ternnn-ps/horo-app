# 03: หมอดูกดขอถอนเงิน

**What to build:** หมอดูเห็นยอดที่ถอนได้จริง (แยกจากยอดค้างจ่ายทั้งหมด) เห็นว่ายอดที่ยังถอนไม่ได้
จะถอนได้เมื่อไหร่ เห็นขั้นต่ำ · กรอกจำนวนแล้วเห็นตัวอย่างว่าจะได้เงินจริงกี่บาทหลังหักค่าธรรมเนียม
และภาษี **ก่อน**กดยืนยัน · กดแล้วยอดค้างจ่ายลดลงทันที

**นี่คือก้อนที่ทำให้วงจรเงินครบสองด้านเป็นครั้งแรก**

**Blocked by:** 01 (รายการรายได้), 02 (บัญชีธนาคาร + KYC)

**Status:** ready-for-agent

- [ ] ยอดถอนได้นับเฉพาะรายได้ที่เก่ากว่าระยะรอที่ตั้งไว้ — รายได้เมื่อวานต้องยังถอนไม่ได้
- [ ] บัญชียังไม่ผ่านการตรวจ → ขอถอนไม่ได้ พร้อมเหตุผลที่อ่านรู้เรื่อง
- [ ] ต่ำกว่าขั้นต่ำ → ขอถอนไม่ได้
- [ ] ขอเกินยอดที่ถอนได้ → ถูกปฏิเสธ และเหรียญไม่ขยับแม้แต่หน่วยเดียว
- [ ] ขอสำเร็จ → เหรียญออกจากยอดค้างจ่าย **ทันทีตอนขอ** ไม่ใช่ตอนโอน
- [ ] มีคำขอค้างอยู่แล้วขออีก → ถูกปฏิเสธ (กันถอนซ้อน)
- [ ] อัตราแลกเปลี่ยน ค่าธรรมเนียม และภาษีถูก snapshot ไว้ในคำขอ — เปลี่ยนค่ากลางทีหลังแล้วคำขอเก่าไม่เปลี่ยนตาม
- [ ] ตัวเลขที่แอปแสดงก่อนกดยืนยัน ตรงกับที่บันทึกจริงในคำขอ
- [ ] ledger สมดุลหลังขอถอน
- [ ] ค่ากลางทั้งหมด (อัตราแลก ค่าธรรมเนียม ภาษี ขั้นต่ำ ระยะรอ) อ่านจาก config ไม่ได้ฝังในโค้ด
